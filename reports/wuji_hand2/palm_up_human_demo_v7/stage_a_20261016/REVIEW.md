## 接触位置复核：原门槛的局限

冻结评估器所调用的 `contact_forces()` 将每根手指的 `*_distal` 末节本体与 `*_tip_sensor_frame` 指尖传感区域**合并**到同一“指尖”力通道；v7 训练环境也以相同方式合并接触。因此原指标的 `two_tip_fraction > 0.95` 不能单独证明两个指尖传感区域同时接触。为检查这一点，[独立审计脚本](../../../../tools/audit_wuji_v7_contacts.py)在不改策略或原评估器的情况下，重放同一模型、种子和 24 回合，逐项复现了原始评估指标，并记录所有 5280 帧的实际接触本体、力及局部/世界坐标。

| 24 回合接触诊断 | 结果 |
| --- | ---: |
| 原规则“双指尖”接触帧比例 | 每回合 95.9%–99.1% |
| **只计指尖传感区域**的双接触帧比例 | 每回合 **75.0%–78.2%**；若沿用 95% 门槛，**0/24** |
| 末节本体接触力超过 0.05 N 的帧比例 | 每回合 24.5%–30.0% |
| 其中中指末节本体接触 | 每回合 22.3%–26.8% |
| 其中拇指末节本体接触 | 每回合 3.6%–6.8% |
| 按 v7 训练环境的局部 y < 1 mm 定义、侧面样接触合力 > 0.05 N | 每回合 36.4%–49.5% |

[逐回合审计摘要](contact_audit/contact_audit.json) · [逐帧本体受力](contact_audit/contact_frames.json) · [全部 24 回合接触点、力和坐标（gzip JSON）](contact_audit/contact_points_all_episodes.json.gz)。首回合中指末节承力集中在约 **1.25–1.65 秒**和 **2.75–3.30 秒**，可直接在视频相应位置检查。只计指尖传感区域与侧面样接触均是额外的位置诊断；须结合手模型几何校准真实指腹区域，不能只凭本体名称或一个局部坐标阈值断言动作一定不自然。

## 真人参考并排审阅

[真人参考 A](../baseline_20261015/human_A.mp4) 的 SHA256 为 `5ffe284d73e0a07d24beff5b8b3d955cfcb8f2b0a38cd829cf498be973ec720a`。机器人视频为同一时间步的三视角闭环策略；真人片段是单视角，双方尚未做时间或相位对齐。抽帧可见机器人保持笔在拇指、食指和中指附近转动，原始骨链检查在首回合未记录投影交叉；真人片段中的部分接触位置被手指遮挡。二维画面不能确认被遮挡处的实际力、指腹面积或三维交接。

请在[并排卡片](review.html)重点审阅：1. 食指与中指是否在真实释放后交接；2. 上述中指末节承力是否是可接受的指腹接触，还是侧面/指节托笔；3. 末端回夹与真人参考的姿态是否一致。当前**人工动作结论：待用户确认**。在接触位置和自然性未通过前，不把该策略作为合格示范或启动 60 秒训练；修正路线见[下一阶段计划](../NEXT_STAGE_PLAN.md)。
