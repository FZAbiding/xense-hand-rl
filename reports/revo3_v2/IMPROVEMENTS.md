# V2 为什么减少了无名指、小拇指的抽搐

结论：最直接的改变是**目标位置的变化方式与每步幅度**，再配合有余量的抓姿、限位处理、接触奖励与长回合训练。不是锁死两根手指，也不是换了更大的网络或增加了真实硅胶层。

## 1. 从“每步重新指定大幅位置”改为“在上一步目标上小步移动”

V1：`目标 = 初始抓姿 + 0.65 × 动作`，再裁剪至关节限位。所有21个关节共用0.65rad尺度；若连续两步动作变化0.1，未裁剪目标就变化约3.72°。极端动作由-1变+1时，未裁剪目标差可达74.5°；这是理论上界，不代表每步实际发生。

V2：`本步目标 = 上步目标 + 逐关节步长 × 动作`。步长随关节范围缩放，并设上限。无名指、小拇指的步长再乘0.5，因此在25ms控制周期内：

| 两根手指的关节 | 最大目标变化/步 |
|---|---:|
| MPR侧摆 | 0.45° |
| MCP、PIP、DIP屈伸 | 约1.003° |

限制的是**命令目标变化速度**，不是保证实际关节速度绝不超过此值；动力学仍由执行器、惯性和接触决定。全部21个关节仍可运动，碰撞仍启用，笔仍是受重力的自由刚体。

## 2. 不再从“贴限位的抓姿”开始

V1有11/21个初始目标距限位不足2°；原诊断约41%的关节×时刻目标被裁剪。部分动作输出虽然变化，实际执行目标却卡在边界，离开边界时又突然恢复响应。

V2从96个候选中筛选3个通过重力/接触测试的抓姿；初始控制目标最小限位余量约3.6°。初始IK主要优化拇指、食指、中指，无名指/小指从较保守弯曲姿态起步，但训练后不固定。运行时增加软限位余量，并将指令裁剪惩罚从先导0.2提高到3。

这使策略有空间进行小幅修正，而不是反复产生限位外指令。没有扩大官方模型的关节活动范围。

## 3. 给增量控制补上必要状态

观测由81维增加到109维：增加21维当前目标位置和7维接触法向力统计。策略不必仅从关节实际位置猜测“上一目标积累到了哪里”，也能区分远端指节、其他指节与掌心受力。

这些接触力是仿真特权信息，不能直接假定实物具备同样传感器。接触区域按远端刚体分类，也尚未精细区分软指腹。

## 4. 奖励不再鼓励额外手指为了接触计数而参与

V1接触数奖励在3指时封顶；V2在2指达到支撑奖励上限，不再仅因增加第3个接触获得额外支撑分。新增/强化了水平姿态、非指尖/掌心承载、过大法向力和指令裁剪的约束。

这给无名指、小指“需要时参与，不需要时少动”的空间。并不是禁止第3、4、5指接触；它们若有利于跟踪和稳定，仍会使用。

需要特别纠正一个容易误解的点：**V1本来就有动作差分平滑惩罚，V2并非只是把它加大。** V1系数0.01，V2为0.005，不能直接比较效果：V1动作差分对应目标位置差；V2动作本身已对应目标增量，其差分更接近目标增量的变化。控制语义变了，系数不是同一个物理尺度。

## 5. 训练和选模也做了改变

- 回合从12秒延长到60秒，让策略经历多次换向后的目标累积与接触漂移。早期V2曾短时好看、长时掉笔；第650轮以后才解决小幅长时验收。
- PPO增加完整采样批次KL检查、异常更新回退和学习率调整，减少单次大更新破坏已有动作。
- 不是选最后一轮或loss最低的一轮。中幅第1050轮loss更低却更容易掉笔，因此归档验证更好的第1000轮。
- 先小幅、低速，再升级幅度和速度。用户看到的V2中幅是±20.1°/6s，V1是±34.4°/4s；任务更温和也有帮助，不能把全部改善都归因于控制改动。

## 6. 轨迹中实际看到了什么

从各自前三个保存回合的前12秒，按40Hz关节位置计算：

| 指标 | V1原任务 | V2中幅 |
|---|---:|---:|
| 无名指每步实际角度变化P95 | 4.60° | 0.365° |
| 小拇指每步实际角度变化P95 | 4.65° | 0.432° |
| 无名指平均绝对角速度 | 68.48°/s | 4.87°/s |
| 小拇指平均绝对角速度 | 70.02°/s | 6.06°/s |

这支持“视频里两根手指明显更稳定”的观察，但**不是同幅同速消融**：两者幅度、周期、抓姿、训练预算都不同。40Hz有限差分也不能辨识20Hz以上振动。原始数据见 [finger_motion_v1_v2.json](finger_motion_v1_v2.json)。

此前不能仅凭上述不同任务的数据作公平归因；现在已完成±0.6rad、4s的固定CPU验证，可与V1原任务进行同幅同速对比。单项贡献百分比仍需要额外受控消融，不编造归因。

### 后续补充：同幅同速仍然改善

V1与V2第1600轮均采用±0.6rad/4s、相同CPU后端、相同种子20260925、12回合×60s、不复位；这消除了前一组幅度和速度差异，但抓姿、控制、奖励、观测和训练预算仍不同。

| 指标 | V1 | V2第1600轮 |
|---|---:|---:|
| 无名指单步角度变化P95 | 4.444° | 0.524° |
| 小拇指单步角度变化P95 | 4.239° | 0.356° |
| 无名指平均绝对角速度 | 71.19°/s | 7.57°/s |
| 小拇指平均绝对角速度 | 68.13°/s | 4.95°/s |
| 笔平均倾斜 | 30.380° | 0.298° |
| 命令裁剪比例 | 40.726% | 0.137% |
| 角度跟踪MAE | 3.347° | 0.243° |

本表分指P95是每回合P95的平均，取完整60秒，和上一张表“前三回合前12秒的合并P95”口径不同。严格质量通过率为0/12和12/12；V1依然12/12不掉笔，所以不能说V1完全不能抓持，而是运动与姿态质量不满足新标准。
原始同任务数据和完整逐指指标见 [matched_task/README.md](matched_task/README.md)。

注意：上述1600轮只是固定CPU验证集结果。随后GPU119/128、新扰动CPU23/24通过，仍有少数掉笔，**不能据此把1600轮宣布为4秒阶段合格策略**。它说明成功轨迹下动作质量有改善，但鲁棒性仍须独立验收。

### 最终采用1700轮

1700轮完成固定CPU12/12、全新扰动种子CPU24/24、GPU128/128的60秒严格验收，已归档。同幅同速固定CPU比较中，无名指/小指单步角变P95为**0.513°/0.364°**，V1为**4.444°/4.239°**；平均角度误差由3.347°降为0.327°，倾斜由30.380°降为0.358°，命令裁剪由40.726%降为0.397%。

这次大幅阶段还增加了两项工程改进：降低训练探索标准差上限至0.1以缩小随机训练与确定性执行差距；对GPU每个物理子步做约束/接触容量检查，溢出立即拒绝验收。前者与额外训练预算仍有混杂，后者是数据有效性保护，不是奖励或物理作弊。
最终原始对比见 [matched_task_1700/README.md](matched_task_1700/README.md)，完整阶段过程见 [WIDE_STAGE.md](WIDE_STAGE.md)。

## 没有做的改变

没有锁关节、减少自由度、调弱重力、绑定笔、给笔加辅助力，也没有修改官方质量/惯量/关节轴/碰撞网格、位置执行器增益或关节限位。没有完成软硅胶、摩擦、时延和真实电机辨识。

这次改进主要发生在抓姿、控制接口、训练目标和验证方法上，而非凭空改变硬件能力。
