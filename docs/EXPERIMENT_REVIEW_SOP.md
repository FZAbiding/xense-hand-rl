# 灵巧手实验评审与展示 SOP

此规范来自用户对 Wuji v4 的反馈：保留离线 HTML 展示设计，同时防止将不自然的手指交叉动作误报为成功。适用于后续 agent 的仿真、转笔与操作任务。

## 1. 实验隔离和任务约定

新版本先写 `PLAN.md`，明确参考动作、掌面朝向、参与手指、阶段门槛、继承关系和待确认项。每版独立使用 `experiments/`、`assets/`、`runs/`、`artifacts/`、`reports/` 子目录。训练使用明确的可执行配置，不把计划草案传给训练器。保留原始模型关节限位、碰撞、笔质量/尺寸；任何修改必须另存配置、写明依据和假设。

用户要求先人工确认时，先交付可审阅的计划，等待明确答复再训练。不要把本 SOP 当成对其他任务新增审批的理由。

## 2. 参考示范

保留已获授权下载的原片/片段、来源、起止时间、SHA256。区分观察、推测和人工确认；二维投影不能当作三维角度或接触力真值，镜头切换不能拼成完整循环。遮挡下未知的接触顺序必须写明待验证。

## 3. 训练前检查动作可行性

先检查机器人关节轴、正负方向、关节组合、掌面坐标系和真实碰撞。用带手指颜色/编号的俯视、掌侧、侧视图审阅初态及短参考轨迹。

食指和中指的指序、整条指骨空间关系、侧摆幅度与共同屈曲必须符合当前任务的动作约定。**无穿透不等于没有交叉，PIP/DIP 正角度不等于姿态自然。** 不能只看一个投影视角判断三维交叉，也不能仅凭末端顺序判断整条指骨。具体检测阈值必须在当前手模型上校准并记录，不杜撰通用人体数值。

检查实际笔—指腹接触点、笔轴上相对重心的位置、法向/切向力及力矩；避免中节支撑、笔落在指头上、闲置手指阻挡、用自穿透或异常扭指换取角度。保留所有碰撞，不通过关闭碰撞掩盖问题。

## 4. 分阶段验收

分别报告：物理存活、姿态合理性、转动幅度/方向、实际接触对和交接、鲁棒性、人工评审。缺少任何一项时标为“待验证”或“失败”，不能合并成成功率。

从自然夹持、小角度转动、单次交接，再到半圈、整圈、连续循环。失败阶段不能通过加大任务或训练轮数绕过。优化/模仿目标只能来自已通过本阶段姿态和物理检查的参考。

角度必须保留笔端身份并连续展开；不能用无向轴、剪辑、循环播放伪造完整转圈。每个阶段保存未见种子、扰动定义、逐回合记录和失败时刻；掉笔提前结束的回合不能补齐成成功轨迹。

## 5. 保留用户认可的离线 HTML 设计

每次交付 `artifacts/<hand>/<version>/review.html`：

- 深色背景，居中内容区域，响应式卡片网格；宽屏并排，窄屏单列。
- 卡片按真人参考、候选动作、稳定夹持/基线、失败案例组织，各卡清楚标注状态和用途。
- 视频使用本地相对路径，原生播放控件，`preload="metadata"`、`playsinline`；不自动播放、不默认循环。
- 机器人候选至少含两个同一时间步的视角，能看清食指/中指相对位置；配时间、实际/目标角、版本与动作类型。另存带手指编号/颜色的审阅画面。
- 说明该片是实际策略 rollout、开环控制还是几何预演。几何预演不能标为物理成功。
- 真人与机器人卡片便于并排观看；未经时间/相位标定，不声称已同步或已实现相同效果。
- 同页提供关节曲线、接触曲线、指标 JSON、原始轨迹、配置/权重和报告链接。预览图与 MP4 同时保留。
- 顶部优先写实际结论、失败原因和待确认项。失败素材保留原样，用显著标签说明问题，不隐藏、不改成成功样例。

可复用生成器：`tools/render_experiment_review.py`。输入 JSON 中定义 `title`、`summary`、`cards`（`title/status/video/description`）和可选 `images`、`links`。媒体路径相对于输出 HTML 所在目录，必须已存在。示例配置见 v4 的 `review_manifest.json`。

```bash
.venv-warp/bin/python tools/render_experiment_review.py \
  --manifest artifacts/wuji_hand2/palm_up_human_demo_v4/review_manifest.json \
  --output artifacts/wuji_hand2/palm_up_human_demo_v4/review.html
```

## 6. 交付与更正

检查所有本地链接、视频时长/帧数、指标与所选权重的对应关系，保存源文件清单和哈希。运行必要的检查即可；页面文案修改不需要重跑训练。

用户指出不合理动作后，保存原始指标、视频和反馈证据，增加独立的审阅记录；更新页面、报告和机器可读摘要，撤回被否定的自然动作成功结论。旧物理指标可作为历史诊断保留，但不得继续作为新标准下的通过结论。可重建的报告生成器也必须读取更正记录，避免重新生成时恢复旧结论。

最终回复给出实际完成内容、限制、视频入口和下一阶段门槛。不要把“已执行训练”说成“已完成转笔”。
